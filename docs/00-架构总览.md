# Pi × ComfyUI 集成 — 架构总览

> 版本:初版(2026-10-09)
> 状态:设计文档,尚未开始编码
> 相关文档:10-pi扩展 / 20-生成器编写指南 / 30-pi-web插件与wire协议 / 40-comfyui-api备忘 / 50-安装与开发

## 1. 目标

1. **Agent 工具**:为 Pi Coding Agent 提供一组可配置的 ComfyUI 工具。用户通过工作区内的 **JavaScript 工作流生成器文件** 定义工作流;Agent 调用工具、传入参数、得到生成结果(图片/视频/音频落盘到工作区)。**生成工作流的过程与提交细节对 Agent 完全不可见**(Agent 只看到工具描述 + 参数 schema),以节省 token。
2. **实时渲染**:在 pi-web 图形界面中,AI 调用工具后实时渲染执行进度与预览图,并展示最终生成的图片/视频/音频。
3. 生成与提交经由 **gpu-manager 代理**(保证 ComfyUI 与本地 LLM 互斥使用显存),Agent 侧无需感知排队与显存管理。

## 4. 关键数据流

**提交与执行(扩展内,对 Agent 不可见)**

```
comfyui_generate({generator, params, output?})
  → 装载生成器 → 校验 params(JSON Schema,应用 default)→ build(params, ctx).prompt
  → 打开 WS /ws?clientId=X(先发 feature_flags)
  → POST /prompt {prompt, client_id: X}(经 gpu-manager :4100)
  → WS 跟踪:executing / progress(+b_preview 二进制)/ executed / execution_error
  → 终态后 GET /history/{prompt_id} 兜底校验
  → 收割 outputs(通用形态匹配)→ /view 逐文件下载 → 落盘工作区
  → onUpdate 流式回进度;最终 content 给 Agent 一份精简文本(路径清单)
```

**实时 UI(pi-web)**

```
扩展  ── pi.events.emit("pi-comfyui", {kind:"progress"|"preview"|"job"|…}) ──▶ 服务端插件
服务端插件  ── connect({projectId, workspaceId, sessionId}).on("pi-comfyui") 订阅(先订阅后发)
           ── peer.openChannel("live").send(帧) ──▶ 每个打开面板的浏览器标签
浏览器命令(cancel 等)─▶ 服务端插件 ── connection.emit("pi-comfyui", cmd) ──▶ 扩展
```

**产物展示**:落盘后浏览器插件用宿主 `files.listFiles(outputDir)` + `files.previewUrl(path)` 渲染 `<img>/<video>/<audio>`;面板声明 `invalidationResources: ["workspace.files"]`,产物写入自动刷新。

## 5. 约束与信任模型

- **同机文件系统约束**:D8 的路径加载节点按**文件路径**直接读文件,因此 ComfyUI 进程与工作区必须位于同一台机器。当前拓扑满足(工作区、sessiond、ComfyUI 都在节点 A)。若未来工作区跨机(如挂载节点 B),路径加载会失败——二期再考虑 `/upload/image` 方案。
- **生成器是可信用户代码**:生成器在 pi 会话进程内执行,与扩展同等权限(pi 扩展文档的同一信任模型)。生成器文件**不允许 `import`**,保持自包含,降低复杂度。
- **显存互斥交给 gpu-manager**:扩展**不要**调用 `/free`、不要感知 lane;只把 baseUrl 指向 gpu-manager 的 4100 端口。gpu-manager 对 `comfyui` 类型应用全旁路(忙闲由 `/queue` 轮询判定),WS 升级会被透传,`--preview-method auto` 的预览帧可正常到达。
- **事件总线无回放**:`pi.events` 是 fire-and-forget,不保证送达、不缓存历史。浏览器断线期间错过的帧不补发;历史与最终状态以服务端插件的 `peer.request("list")` / 任务历史存储为准。

## 6. 第一期范围 / 非目标

**范围内**

- 单包 `pi-comfyui`:pi 扩展(5 项工具配置能力,默认 2 项启用)+ pi-web 插件(浏览器 + 服务端)
- 生成器装载与运行、ComfyUI 客户端(HTTP+WS)、输出收割落盘、实时预览帧
- pi-web 面板:运行卡片 / 产物画廊 / 任务历史 / 取消
- 配置体系(两级 JSON)、超时/中断/错误处理

**非目标(二期)**

- 全局 applicationPanel 与跨工作区视图
- 跨机工作区的上传方案(`/upload/image`)
- 生成器模板市场、参数表单 UI 调试器
- 多 ComfyUI 实例(仅单 baseUrl)
- ComfyUI 新版 `/api/jobs` 任务 API 的采用(当前用经典 `/prompt` + `/history` + `/ws` 链路,已在本文档 40 备忘)
