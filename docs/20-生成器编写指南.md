# 20 — 工作流生成器编写指南

> 面向:想扩展 Agent 能力的用户(自己写生成器 JS 文件)。生成器是唯一需要"写工作流"的地方;Agent 只见参数 schema。
> 实现依据:10-pi扩展 §4(装载器);ComfyUI API 格式见 40 §3。

## 1. 位置与命名(D2)

```
<你的工作区>/.pi/comfyui/generators/
├── txt2img-sdxl.js        # 一个文件 = 一个生成器
├── img2img-sdxl.js
└── tts-openvoice.js
```

- 扁平一层,仅 `*.js`;文件名(不含 `.js`)作为默认 `name`(可再在导出对象里覆盖)。
- `name` 最终会成为示例展示名与事件帧的标识,建议 `小写-字母数字-连字符`。
- 修改文件**无需重载会话**:每次工具调用都会重新扫描目录(有 mtime 缓存),保存即生效。

## 2. 模块契约

最小骨架:

```js
// txt2img-sdxl.js —— 自包含,禁止 import
export default {
    name: 'txt2img-sdxl', // 可省略(默认取文件名);[a-z][a-z0-9-]{0,63}
    title: 'SDXL 文生图', // 面板与 list_generators 显示
    description: '用 SDXL 生成静态图片;prompt 必填',
    params: {
        type: 'object',
        properties: {
            prompt: { type: 'string', description: '正向提示词' },
            negative: { type: 'string', default: '', description: '负向提示词' },
            width: { type: 'integer', default: 1024, minimum: 256, maximum: 2048 },
            height: { type: 'integer', default: 1024 },
            steps: { type: 'integer', default: 30 },
            seed: { type: 'integer', minimum: 0, description: '缺省为随机' },
        },
        required: ['prompt'],
    },
    build(params, ctx) {
        return {
            prompt: {
                1: { class_type: 'CheckpointLoaderSimple', inputs: { ckpt_name: 'sd_xl_base_1.0.safetensors' } },
                2: { class_type: 'CLIPTextEncode', inputs: { text: params.prompt, clip: ['1', 1] } },
                3: { class_type: 'CLIPTextEncode', inputs: { text: params.negative, clip: ['1', 1] } },
                4: {
                    class_type: 'EmptyLatentImage',
                    inputs: { width: params.width, height: params.height, batch_size: 1 },
                },
                5: {
                    class_type: 'KSampler',
                    inputs: {
                        seed: params.seed ?? Math.floor(Math.random() * 2 ** 31),
                        steps: params.steps,
                        cfg: 7.0,
                        sampler_name: 'euler',
                        scheduler: 'normal',
                        denoise: 1.0,
                        model: ['1', 0],
                        positive: ['2', 0],
                        negative: ['3', 0],
                        latent_image: ['4', 0],
                    },
                },
                6: { class_type: 'VAEDecode', inputs: { samples: ['5', 0], vae: ['1', 2] } },
                7: { class_type: 'SaveImage', inputs: { filename_prefix: `pi/${ctx.token}`, images: ['6', 0] } },
            },
        };
    },
};
```

**契约要点**

| 字段          | 类型                                 | 必需 | 说明                                                                                       |
| ------------- | ------------------------------------ | ---- | ------------------------------------------------------------------------------------------ |
| `name`        | string                               | 否   | 工具引用名;缺省=文件名                                                                     |
| `title`       | string                               | 是   | 显示名                                                                                     |
| `description` | string                               | 是   | **给 Agent 看的一句话**(会进 list_generators 结果);建议 ≤160 字符,写清用途与参数要求       |
| `params`      | JSON Schema object                   | 是   | `type:"object"`;属性顺序即文档顺序;`default` 会被自动应用;`description` 字段会展示给 Agent |
| `build`       | `(params, ctx) => { prompt: graph }` | 是   | 返回 ComfyUI **API 格式** graph(见 §4);多余返回键被忽略                                    |

装载器会校验:default 导出为对象、name 合法、params 为 object schema、build 为函数、**源码不含 `import`/`require`**(自包含约定;这不是安全边界,生成器与扩展同进程同权限,是用户自己写的可信代码)。校验不过的文件会在 `comfyui_list_generators` 结果里列出"无效文件+原因",保存后重新调用即可生效。

## 3. params 设计规范(直接影响 Agent 的调用质量)

- Agent 拿到的信息 = `title` + `description` + **每个属性的 `description`**(经 list_generators)。写参数说明要像给新人看的 API 文档一句一行。
- 有默认值的一定写 `default`(Agent 可省略);必填的进 `required`,并在 description 里说明格式(如"工作区内图片相对路径,如 assets/cat.png")。
- 枚举用 `enum`(如 `aspect_ratio: {enum:["1:1","3:2","2:3"]}`);数字范围写 `minimum/maximum`。非法参数会在提交前被 schema 校验拦下,不消耗 GPU。
- 数量克制:参数 ≤ 8 个为佳;复杂的"风格预设"做成 enum,而不是让 Agent 编 graph。

## 4. graph:ComfyUI API 格式速成

API 格式 = 节点 id → `{class_type, inputs}`;节点间用 `["<上游节点id>", <输出序号>]` 引用。与 UI 里保存的工作流(workflow/pack 格式)不同——**不要**直接粘贴 UI 导出的 `extra_data`。构造要点:

- node id 用短字符串;引用序号看节点类型(通常 checkpoint: 0=model 1=clip 2=vae;KSampler: 0=latent)。
- **至少含一个输出节点**(OUTPUT_NODE=True 的,如 SaveImage/SaveVideo/SaveAudio\*),否则执行完没有任何可收割产物(工具会以"无输出文件"完成,见 10 §9)。
- `filename_prefix` 建议固定写 `` `pi/<ctx.token>` ``——保证输出目录唯一、命名规则(§6)可控。
- 校验失败最快排查:`comfyui_list_generators` 不行时直接看工具错误里的 `node_errors`(POST /prompt 返回,见 40 §2)。

## 5. 输入文件:路径加载节点(D8,无需上传)

| 节点                        | 包                             | 入参(字符串) | 返回        |
| --------------------------- | ------------------------------ | ------------ | ----------- |
| `LoadImageFromPath`         | ComfyUI_Ib_CustomNodes(已装)   | `image`      | IMAGE, MASK |
| `LoadVideoFromPath`         | chlamydomonos-va-loaders(自研) | `video`      | VIDEO       |
| `LoadAudioFromPath`         | chlamydomonos-va-loaders(自研) | `audio`      | AUDIO       |
| `LoadImageFromPathEnhanced` | ComfyUI_Ib_CustomNodes         | 同上增强版   | 见其定义    |

路径解析语义(三个节点一致,源码已核):支持 `name [output]` 注解形式;普通路径**绝对路径原样使用,相对路径相对 ComfyUI 的 input 目录**。因此 generators 里**必须把工作区相对路径转成绝对路径**:

```js
  params: { type:"object", properties: {
    image: { type:"string", description:"工作区内参考图相对路径,如 refs/cat.png" }
  }, required:["image"] },
  build(params, ctx) { return { prompt: {
    …
    "0": { class_type:"LoadImageFromPath", inputs:{ image: ctx.resolvePath(params.image) } },
    …
  }; }
```

**约束**:ComfyUI 与工作区必须同机(当前拓扑满足)。跨机工作区会读到不存在的路径,节点校验(VAILDATE_INPUTS)会报 `Invalid image path: …`,该错误会原样到达工具结果,便于定位。若 target 部署缺少这些节点(如迁移环境),工作流会在 node 校验报"节点不存在"。

## 6. 输出与文件名(D6:Agent 决定名字)

- 收割器扫描 `history[prompt_id].outputs` 中所有"文件引用"形态(数组元素含 `filename`+`subfolder`+`type`),与按键名无关(images/audio/videos/gifs/latents/3d… 自动识别,详见 40 §5)。
- 保存位置:工具调用时 Agent 指定 `output.dir`(默认 `comfyui-output`)与 `output.name`(如 `sunset`):
    - 单产物 → `comfyui-output/sunset.png`;
    - 多产物 → `sunset.png, sunset-2.png, …`(按 history 中节点 id 升序 + 文件序);
    - 未给 `name` → 保留 ComfyUI 原文件名(如 `pi/ab12cd_00003_.png` 的 basename)。
- Agent 也可以在最终回答里把路径告诉用户、或用文件工具引用它们;pi-web 面板的画廊按目录列出全部产物(与任务无关按目录聚合)。

## 7. 预览(生成器侧注意事项)(D5)

- **生成器无需写任何预览节点**。部署已带 `--preview-method auto`,执行期采样预览自动经 WS 推给扩展,进而在 pi-web 面板实时显示。
- 预览帧大小可被扩展缩放/限频(见 10 §6),生成器侧不用管。
- 部署没开 `--preview-method` 时:没有预览,**面板不渲染预览区**(不是错误),生成照常。

## 8. 调试清单

1. `comfyui_list_generators` 里看文件是否"有效"+原因(装载/校验错误)。
2. generate 失败时看 content:
    - "节点 X 校验失败…" → params 传错或缺 required(graph 校验,POST /prompt 400);
    - "Invalid image path" → 输入文件路径错/跨机;
    - "class_type 不存在" → 目标部署缺该节点包。
3. 想查节点真实入参 → `GET /object_info/<class_type>`(经 gpu-manager :4100 也可)。
4. 排查提交内容:临时在 build 里 `throw new Error(JSON.stringify(prompt))` 看错误消息(调试完删掉)。

## 9. 完整示例:img2img(输入文件 + 输出命名)

```js
// img2img-sdxl.js
export default {
    name: 'img2img-sdxl',
    title: 'SDXL 图生图',
    description: '以工作区图片为底进行 img2img;image 必填(工作区相对路径),strength 控制重绘幅度',
    params: {
        type: 'object',
        properties: {
            image: { type: 'string', description: '工作区内图片相对路径,如 refs/sketch.png' },
            prompt: { type: 'string' },
            negative: { type: 'string', default: '' },
            strength: { type: 'number', default: 0.6, minimum: 0, maximum: 1, description: '1=完全重画,0=不动原图' },
        },
        required: ['image', 'prompt'],
    },
    build(params, ctx) {
        return {
            prompt: {
                1: { class_type: 'CheckpointLoaderSimple', inputs: { ckpt_name: 'sd_xl_base_1.0.safetensors' } },
                2: { class_type: 'LoadImageFromPath', inputs: { image: ctx.resolvePath(params.image) } },
                3: { class_type: 'CLIPTextEncode', inputs: { text: params.prompt, clip: ['1', 1] } },
                4: { class_type: 'CLIPTextEncode', inputs: { text: params.negative, clip: ['1', 1] } },
                5: { class_type: 'VAEEncode', inputs: { pixels: ['2', 0], vae: ['1', 2] } },
                6: {
                    class_type: 'KSampler',
                    inputs: {
                        seed: Math.floor(Math.random() * 2 ** 31),
                        steps: 30,
                        cfg: 7.0,
                        sampler_name: 'euler',
                        scheduler: 'normal',
                        denoise: params.strength,
                        model: ['1', 0],
                        positive: ['3', 0],
                        negative: ['4', 0],
                        latent_image: ['5', 0],
                    },
                },
                7: { class_type: 'VAEDecode', inputs: { samples: ['6', 0], vae: ['1', 2] } },
                8: { class_type: 'SaveImage', inputs: { filename_prefix: `pi/${ctx.token}`, images: ['7', 0] } },
            },
        };
    },
};
```

调用(对 Agent 完全透明,只需两步):

```
comfyui_list_generators()            // 找到 img2img-sdxl 与参数
comfyui_generate({ generator:"img2img-sdxl",
                   params:{ image:"refs/sketch.png", prompt:"garden" },
                   output:{ name:"garden-img2img" } })
// 最终 content: comfyui-output/garden-img2img.png …
```
